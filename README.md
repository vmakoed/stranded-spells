# Godot Game Template

This is a submission to [Brackeys Game Jam 2026.1](https://itch.io/jam/brackeys-15).

Play: https://rubybit.itch.io/stranded-spells

Stranded Spells is a 2D Action game where players take the role of a wizard trapped in a dungeon full of enemies. Combat relies on a unique spell-casting mechanic inspired by fighting game inputs. A player must find their way through rooms connected in unpredictable ways and learn how to exploit enemy weaknesses with their spell toolkit.
